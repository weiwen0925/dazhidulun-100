般若

能說是因緣，善滅諸戲論；
我稽首禮佛，諸說中第一。

本品為卷一百開卷之首，亦是《大智度論》接近全論收結處的關鍵入口。佛陀親自為常啼菩薩、曇無竭菩薩兩位「般若代言人」設定論辯舞臺──前者代表「捨己求法」的決絕心，後者代表「示現般若」的圓熟智；兩尊對境拉出「般若是諸佛師 vs 諸佛說般若」這條中觀辯證的引線。論主於本品建立全卷的提綱：原典經文逐句疏解、般若明鏡矩陣、中觀因果論的悖論與重塑、實修心法「從二等到離二邊」，皆於此奠基。

本品搭好雙尊對境的舞臺後，第二品將深入經文原典本身──《般若》十九相與六百萬三昧門的修證地圖、中觀辯證引擎於「平等／因果悖論」上的展開、以及「離義 · 二度解構與《中論》空亦復空」的核心論證。請帶著本品建立的「般若是顯現非創造」這條主線，進入第二品的密度更高的解析。

前往第二品 · 釋曇無竭品 · 修證引擎 →

承第一品奠定的論辯結構，本品深入「般若是諸佛師」這個顯題的內部運作：第一節以開卷導論的全景圖把般若 19 相與六百萬三昧門的修證梯度展開；第二節以經文原典逐句對讀；第三節揭示中觀辯證的引擎──「平等」與「因果」兩個看似矛盾命題之間的張力如何同時成立。隨後依「平等義 → 離義 → 不動／無念／無畏 → 一味與無邊 → 總持四維度」八章層層推進，把「般若是顯現非創造」徹底落實在心理機制與境界昇華的雙軌上。

第二品已把釋曇無竭品的修證引擎完整拆裝。第三品「般若實相與中觀修證」則站在更高俯瞰位置──不再線性疏解經文，而是把「破微細法執 → 般若 22 段 → 從平等到無邊 → 渡海喻 → 須彌山喻 → 金剛三昧 → 從解到證 → 捨般若 → 六百萬三昧」整合為一張中觀修證地圖。它同時銜接卷一百兩品（釋曇無竭品 + 釋囑累品），是承上啟下的核心樞紐。

前往第三品 · 般若實相 · 中觀修證 →

本品是卷一百的中軸樞紐。它不依品次線性疏解，而是把全卷拆成 11 個修證階梯：從「破微細法執的對話」開場（捨般若 = 法愛即垢染的最後關卡），經「般若 22 段相」、「從平等到無邊的辯證」、「渡海喻」、「須彌山喻」、「金剛三昧（宏觀／微觀無邊）」、「從解到證 · 七年立定的轉化」，最終以「六百萬三昧 · 證悟果報莊嚴」與「釋囑累品最後對話」收尾。第十一章「般若實相與修證地圖」是卷一百的終極總持圖。

第三品搭好中觀修證的全景地圖後，第四品轉入「釋囑累品第九十」的辯證解構──佛陀以「金剛冶煉」般的六重悖論囑累阿難（法愛、器局、對象、體用、中道、契約），讓般若在最後一刻仍須經受最嚴酷的中觀考驗。請以第三品的「捨般若／離法愛」為心法基準，進入第四品的六重難辯。

前往第四品 · 釋囑累品 · 六重悖論 →

本品是釋囑累品的「金剛冶煉場」。佛陀將般若囑累阿難三遍，並由論主以六重悖論的辯證引擎──法愛、器局、對象、體用、中道、契約──逐一錘鍊：第三章「敬佛輕法」破法愛悖論；第四章「三千大千能否盛器」破器局悖論；第五章「囑累對象之謎」破對象悖論；第六章「般若與佛的體用」破體用悖論；第七章「囑累如虛空斷滅否」破中道悖論；第八章「眾生帶業見佛」破契約悖論。終以第九章「二諦矩陣全圖」與第十章「大眾歡喜奉行」收結。

第四品以六重悖論完成中觀辯證的最後試煉；第五品則對「釋囑累品第九十」做最後一輪總攝──從七番設問總覽、法愛／制度／中道／業力／境界／結集六大悖論，到「法佛不二的終極閉環」。第五品的視角與第四品有所重疊但更聚焦於「囑累儀軌如何在第一義諦與世俗諦之間架橋」，是卷一百最後的圓滿之鑰。

前往第五品 · 釋囑累品 · 全論收結 →

本品是《大智度論》一百卷的最終收結。論主以「從文獻交接到第一義諦／世俗諦的終極橋樑」為序章，將「囑累儀軌」抬升到中觀辯證的座標系；隨後以七番設問鋪展──法愛、制度、中道、業力、境界、結集六大悖論──全面回應「般若是諸佛師何以不入三藏／阿羅漢何以大歡喜／帶業可否見佛」等卷末懸問。終章「法佛不二的終極閉環」回到本卷起首「般若是諸佛師」的引線，圓滿收口。

第五品收結後，卷一百已圓滿；全《大智度論》一百卷的論述至此告一段落。讀者可回到「總目錄」重溫五品脈絡，或依「卷 → 品 → 章 → 節」順序回看任一章節──般若是諸佛師、諸佛說般若；法 + 佛、不二而不一；囑累已畢，皆大歡喜。
